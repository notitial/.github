## About

Notitial is a one-person engineering lab. It is where I build the things I
want to exist and run them on hardware I own: self-hosted apps, tooling for
working with AI agents, and the infrastructure that keeps all of it running at
home.

Everything is built to be deployed the same way. A push to `main` runs the
checks, builds an image, and ships it to the home server, with no manual steps
between commit and running app.

## What lives here

| | |
|---|---|
| **Apps** | Self-hosted web apps, built and deployed from their own repos |
| **Agent tooling** | Rules, hooks and workflows for working with AI coding agents |
| **Infrastructure** | The configuration, runbooks and decisions behind the homelab |

Most repositories are private. Anything public will show up in the pinned
repositories above this section.
